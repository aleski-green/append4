# Vendored LMDB

Unmodified LMDB 0.9.36 sources from the OpenLDAP project's official mirror:
https://github.com/LMDB/lmdb/tree/028f61b6832032174f893484719ed4848d8d60db/libraries/liblmdb

Tag: `LMDB_0.9.36`. The source files retain the OpenLDAP Public License and
copyright notices in `LICENSE` and `COPYRIGHT`. Only `mdb.c` and `midl.c` are
compiled. No external LMDB installation or Haskell LMDB package is required.

Append4's Haskell binding and adapter are separate from these upstream sources.
